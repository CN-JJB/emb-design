# 电子模块

板外成品模块。设计拓展板时，这些模块要么插在板上（需要插座），要么走线束连接。

**手册、针序、尺寸在 [`devices/`](../../devices/README.md)，本目录只记手上有几块。**
两边用同一个 `id`。不要把 PDF 复制一份到这里。

还没有 devices 档案的模块（目前 `p23c`），规格暂时写在本卡片，补档案后改成只留指针。

**⚠ 模块的插座封装一律不许按名称推测。** 仍缺的尺寸见 [待补清单](../pending.md)。

> P23C 与 YB-MPP01 都是给树莓派/RDK/K230 一类视觉主控供电的 12 V→5 V 大电流降压板，
> 在电源树上与电机驱动板同级，不是电机驱动器。**两块只会选用一块。**
