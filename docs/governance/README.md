# Governance

本目录定义 emb-design 的长期资料体系。结构调整、批量整理、新增器件/物料、KiCad 资源维护，均先遵守这里的规则。

阅读顺序：

1. [repository-architecture.md](repository-architecture.md) — 顶层数据模型与“谁是事实来源”
2. [verification-policy.md](verification-policy.md) — 什么资料能证明什么事实、冲突如何处理
3. [maintenance-workflow.md](maintenance-workflow.md) — 新增、更新、整理、删除的标准流程
4. [normalization-plan.md](normalization-plan.md) — 现有仓库逐步整改顺序

核心原则：**证据优先、单一事实来源、库存与器件分离、EDA 与实物绑定、未确认资料隔离、可机器校验。**
