# 线材与线束辅材

导线、成品转接线、热缩管、编织网管、管型端子。

> **线规是保险丝定值的约束**：12 V 大电流支路（电机、视觉板）只能用 18 AWG 硅胶线。
> 用 22 AWG 接 10 A 保险丝的支路，软短路会先烧穿导线而保险丝不动作。
