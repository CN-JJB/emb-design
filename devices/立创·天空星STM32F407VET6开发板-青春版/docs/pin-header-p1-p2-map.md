# P1 / P2 双排针逐针对应表

两组 2×20、2.54 mm 排针共 80 针（青春版不随板焊接，需自行焊排针）。下表由官方嘉立创 EDA
工程 `立创梁山派·天空星开发板_2024-01-17.epro` 的「双路 80pin 排针」页反解得到（机器提取
符号引脚坐标 → 导线连通域 → 网络标签），可直接用于设计拓展板底座，不必再逐针对照丝印照片。

机械参数（板外形取自官方尺寸图；排针坐标取自 `.epro` 里 PCB 的实际元件与焊盘数据）：

- 板外形 45.0 × 69.9 mm。
- 每排 20 行，首尾针中心距 48.26 mm（19 × 2.54）。
- **两排的 `P1-1` 与 `P2-1` 相距 35.56 mm（14 × 2.54）** ——
  这是设计底座时唯一该用的那个数（见下方「⚠ 两个会让底座插不上的坑」）。

- 丝印色块按「偶数针 | 奇数针」成对印刷，例如 P2 顶部的 `C09|D03` 即 2 脚 PC9、1 脚 PD3。

### ⚠ 两个会让底座插不上的坑

这两条都不是"注意事项"，是**错了板子直接报废**的量。本仓库都踩过一次，
所以把复核方法一并写在这里。

**坑 1：两排间距是 35.56 mm，不是 33.02 mm。**

`.epro` 里 P1 是元件 `e57`（x = −700 mil）、P2 是 `e56`（x = +700 mil），
中心相距 1400 mil = **35.56 mm**。两种旋转方向约定算出来都是 1400 mil，
与约定无关，所以这个数是硬的。

33.02 mm（1300 mil）量的是**两排的内侧列之间**的空档，不是任何一对同名针的距离。
把它当成间距用，40 对针会同时错开一个位距。

> 旁证：开发板的 4 个 M3 装配孔在 x = ±706.69 mil，两排排针的中心线 ±700 几乎
> 正压在孔位上——排针跨装配孔是很典型的画法；若真是 ±650，会莫名内缩 1.4 mm。

复核方法：解包 `.epro`（就是 ZIP），读 `PCB/*.epcb` 里两条 `["COMPONENT",...]`
记录的 x 坐标，相减。单位是 mil（同一文件里 `FOOTPRINT/*.efoo` 的相邻针间距是
100，对应 2.54 mm）。

**坑 2：底座的排母封装不能用 KiCad 的 `PinSocket`，要用 `PinHeader` 的手性。**

```
KiCad  PinSocket_2x20   pin1 (0,0)   pin2 (-2.54, 0)   ← 奇列在右
KiCad  PinHeader_2x20   pin1 (0,0)   pin2 (+2.54, 0)   ← 奇列在左
两者焊盘 1.7 mm、钻孔 1.0 mm 完全相同，差别只有"哪个孔叫第几脚"
```

本板是**排针朝下、正面朝上叠在底座上**。从上往下看，本板的 pin2 就在 pin1 的
+X 侧；那么底座上接它的那个孔也必须在 pin1 的 +X 侧——**底座孔位与排针同手性，
不镜像**。KiCad 的 `PinSocket` 是给"两板对插、其中一块翻面"准备的，天生镜像，
用在叠板上会让整排左右翻，且**网表检查、DRC 全都不会报错**。

另外：P1 与 P2 在 `.epro` 里用的是**同一个封装、同一个 −90° 旋转**，所以两排
手性必然一致，不存在"奇在外、偶在内"的镜像对称排法。

特殊网络：

- `PIN_IN_+5V`：5 V 输入。USB-C 的 VBUS 到该针之间只有自恢复保险丝 F1，**没有隔离二极管**；
  外部给 5 V 供电时若同时插 USB，会与 USB VBUS 直接并联互灌，需用跳线断开其一。
- `+3V3`：板载 LDO（SCJA1117B，AMS1117 类）输出，压差较大，不要再串二极管进 5 V 输入。
- `EXT_PIN_VERF+`（P1-2）：外部基准 REF3030 位置，青春版**未安装**，不是可用的 3.0 V 基准。
- `EXT_BAT_PIN+`（P2-26）：RTC 备用电池位置，青春版**未安装**。
- `AGND`（P1-37）：模拟地。
