# 模块识别、接线、I²S 与首次采集

## 1. 已知对象

当前实物资料对应 telesky 圆形模块，商品编码 `MK025336`，标题写 **INMP441 麦克风模块（国产版，已焊接排针）**。

从保留的照片可以确认：

- 圆形 PCB，商家标注直径约 14 mm。
- 两排互相独立的 1×3 排针，商家标注排距约 12 mm。
- 丝印一侧可见 `L/R`、`WS`、`SCK`、`SD`、`VDD`、`GND`，排针已焊。
- 另一面中央是 MEMS 封装，旁边有两颗小阻容。
- 丝印面中央有孔。真品 INMP441 是底孔麦，声音从封装底面经 PCB 开孔进入；国产版是否同一结构，到货后对着实物看，不要按真品假设去开外壳孔。

没有模块原理图，CHIPEN 没有引出。板上若把 CHIPEN 接到 VDD，则模块常开，固件关不断。

## 3. 模块接线

接线以丝印为准。两组 1×3：

| 丝印 | 作用 | 接到 MCU |
|---|---|---|
| L/R | 声道选择 | GND = 左；VDD = 右 |
| WS | I²S 帧时钟 / LRCLK | 主机 WS 输出 |
| SCK | I²S 位时钟 / BCLK | 主机 SCK 输出 |
| SD | I²S 数据输出 | 主机数据输入 |
| VDD | 电源 | 首次接 3.3 V |
| GND | 地 | GND |

左到右顺序按丝印文字方向在实物上核对，不要按另一家圆板的照片编号 1–6。

商家图里的 ESP32 示例（SCK→GPIO14、SD→GPIO32、WS→GPIO15）只属于他们的演示板。本模块没有固定 GPIO。

L/R 不要留作正式配置的悬空脚。商家写「悬空一般当低电平 / 左声道」，手册没有把悬空规定为合法状态。

## 4. I²S 配置

主控必须是 I²S 主机，麦克风是从机。手册强制：

1. 格式为 Philips I²S（不是左对齐、也不是 PCM 短帧）。
2. 每个 WS 周期 64 个 SCK，即每声道 32 bit 槽，有效数据 24 bit，MSB 先出，相对半帧起点延迟 1 个时钟。
3. 采样率 = WS 频率。例如 16 kHz → SCK = 1.024 MHz；48 kHz → SCK = 3.072 MHz（仍低于 3.2 MHz 上限）。

驱动里若把槽宽设成 16 bit，数据会错位。读样本时取每个 32 bit 词的高 24 bit（或按所用 HAL 的 24-in-32 配置）。

SD 在不输出本声道时为高阻。单麦也建议在 SD 对地加 100 kΩ 下拉；双麦共用 SD 时这条下拉是手册明确要求。

上电后前 2^18 个 SCK 周期输出为 0（SCK = 3.072 MHz 时约 85 ms）。VDD 未上电时不要送 SCK/WS，手册写会正偏 ESD 二极管。

## 5. 双麦共用一组 I²S

手册 Figure 7：两颗麦克风共享 SCK、WS、SD。

| 麦克风 | L/R | 输出时隙 |
|---|---|---|
| A | GND | 左 |
| B | VDD | 右 |

SD 汇合后进 MCU，总线加 100 kΩ 下拉。WS 同步两颗麦；若两颗不是同时使能，手册给出最多约 0.35 ms 的对齐时间。模块没有 CHIPEN，做不到手册里的分别关断。

主 PCB 插座画成**两个独立 1×3 排母**，不要先画成标准 2.54 mm 的 2×3。孔位、声孔、排针相对圆板的旋转角都要到货卡尺复核后再定封装。

## 7. 首次采集

1. 断电看丝印，确认 VDD / GND 没有接反。
2. VDD 接 3.3 V，共地，L/R 先接地（左声道）。
3. 配置 I²S 主机：Philips、64×SCK/帧、24 bit 数据。
4. 上电后等约 100 ms 再取数。
5. 对麦说话，左声道应有幅度；把 L/R 改接到 3.3 V 后，数据应出现在右声道。
6. 若完全无数据：先查 SCK/WS 是否在跳、SD 是否被下拉、槽宽是不是 32 bit。
7. 到货后读 MEMS 封装丝印，对照手册第 19 页的 `441` 标记；对不上就不要再按 INMP441 的灵敏度/底孔去设计声学结构。
