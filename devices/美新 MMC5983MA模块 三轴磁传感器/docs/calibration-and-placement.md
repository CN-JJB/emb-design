# SET/RESET、校准、航向角与安装注意事项

## 1. 三种容易混淆的补偿

| 层次 | 要解决的问题 | 方法 |
|---|---|---|
| AMR 桥路恢复 | 强磁场使磁畴偏转、桥路状态改变 | SET/RESET；超过约 10 G 干扰后必须执行 |
| 传感器桥路 offset | 温度引起的内部零点变化 | SET 测量与 RESET 测量求差/求和 |
| 整机磁校准 | 电机、磁铁、钢件、电流和结构造成 hard/soft iron | 旋转采样，求偏置向量和 3×3 校正矩阵 |

启用 `Auto_SR_en` 不等于完成整机校准。SET/RESET 是芯片内部机制，hard-iron/soft-iron 校准必须在模块装入最终设备后重新进行。

## 2. 单轴快速校准

如果只需要初步验证，可让设备在尽可能均匀的地磁场中覆盖多个方向，记录每轴最小值和最大值：

```text
bias_i = (max_i + min_i) / 2
radius_i = (max_i - min_i) / 2
```

先减去 `bias_i`，再把三轴半径缩放到共同平均半径。这能校正 hard-iron 偏置和部分轴向比例误差，但不能完整处理非正交、交叉轴耦合和任意方向 soft-iron 变形。

## 3. 推荐的椭球校准

高质量标定应在最终装配状态下采集覆盖三维姿态的数据，使未经校准的点云从偏心椭球变换为以原点为中心的球：

```text
m_corrected = A × (m_raw - b)
```

- `b`：3×1 hard-iron 偏置向量。
- `A`：3×3 soft-iron、比例和非正交校正矩阵。

采集时：

1. 远离桌腿、电脑磁铁、扬声器和大电流电源。
2. 缓慢覆盖尽可能多的三维朝向，不要只在水平面画“8”字。
3. 剔除饱和、通信错误和瞬态尖峰。
4. 拟合后检查校正点云半径是否集中、中心是否接近零。
5. 把矩阵和偏置写入设备配置，并保存校准时间与安装版本。

可参考 Analog Devices [Hard & Soft Iron Correction for Magnetometer Measurements](https://ez.analog.com/mems/w/documents/4493/hard-soft-iron-correction-for-magnetometer-measurements) 和 VectorNav [Magnetometer Hard & Soft Iron Calibration](https://www.vectornav.com/resources/inertial-navigation-primer/specifications--and--error-budgets/specs-hsicalibration)。它们不是 MMC5983MA 专用驱动，但校准模型适用。

## 4. 航向角

设备严格水平、轴映射已经确认、磁校准已经完成时，可从水平面两轴计算：

```text
heading = atan2(Y, X)
```

实际工程可能需要交换 X/Y 或反转符号，取决于模块安装方向和期望的机体坐标。SparkFun 示例使用 `atan2(X, -Y)`，这是针对其板卡轴向的选择，不能直接证明当前淘宝模块也应使用同一公式。

还需要处理：

- 把弧度转换为 0–360°。
- 根据使用地点加入磁偏角，得到真北而不是磁北。
- 在设备倾斜时使用加速度计进行 tilt compensation；三轴磁传感器本身不能知道重力方向。
- 对动态平台应用低通、异常值检测和运动状态判断。

## 5. 安装位置

官方数据手册的硬件布局要求应视为强约束：

- 远离永磁体、扬声器、电机、继电器、线圈和功率电感。
- 不要让大电流走线从传感器下方或 PCB 背面穿过。
- 不要用可能磁化的屏蔽罩、钢螺丝、铁质支架或电池紧贴传感器。
- 测量场与干扰场的合成值应保持在 ±8 G 量程内。
- 如果必须靠近干扰源，尽量把传感器移到独立小板末端并固定线束形态。

模块最终安装后，电流大小、线束位置、外壳和螺丝变化都会改变校准。量产校准应在最终装配状态和典型工作电流下完成。

## 6. 电流产生的磁场

磁传感器对电源线和电机线非常敏感。长直导线附近的磁场近似与电流成正比、与距离成反比；即使没有永磁体，几安培的电流也能造成明显误差。

实用措施：

- 正负电源线紧密绞合，让磁场尽量抵消。
- 传感器远离电机相线、DC/DC 电感和大电流铜排。
- 在不同负载电流下记录三轴变化；若误差与电流高度相关，可建立电流前馈补偿，但物理隔离优先。
- 校准和实际运行的线束路径保持一致。

## 7. 运行时健康检查

建议持续记录：

- 三轴校正前/后的 µT 值。
- 磁场模长 `sqrt(x²+y²+z²)`。
- Status、超时和 I²C 错误计数。
- 最近一次 SET/RESET 时间。
- 温度原始值。
- 当前负载电流或电机状态。

在固定地点，校正后的地磁模长应在合理范围内缓慢变化。突然跳变、持续接近 ±800 µT、轴值粘死或 Product ID 读取异常，都应触发故障或重新初始化，而不是继续输出航向角。

## 8. 验收建议

1. Product ID 连续读取稳定为 `0x30`。
2. 静止状态噪声与所选 BW 相符，没有大量尖峰。
3. 绕三轴旋转时数据连续，没有饱和和符号错误。
4. SET/RESET 前后能得到合理桥路 offset。
5. 三维校准后点云接近球面，模长波动明显下降。
6. 上电、复位和总线故障后驱动能够超时并恢复。
7. 电机、继电器和最大负载开启时重新检查磁场偏移。

所有校准参数应与模块序列、安装方向和设备硬件版本绑定；更换模块或改变安装位置后重新标定。
