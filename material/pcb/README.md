# PCB 元器件

可直接焊在自制 PCB 上的分立器件。**画原理图选型时优先从本表挑，不够再补购。**

每个型号一个文件夹，手册放在该型号自己的目录里，不要堆回 `material/` 根下。

## C 编号的用途

**元件全部在淘宝/立创自行采购、手工焊接，不走立创 PCBA。**
所以表里的 C 编号**只有一个用途：在嘉立创 EDA 里取到正确的符号与封装**，不用于下单。

判定标准因此只有一条：**封装尺寸必须和手上的实物一致。**

| 记号 | 含义 |
|---|---|
| ✅ `official` | 立创商城实购，型号即实物，封装必然一致 |
| ⚠ `equivalent` | 淘宝实购，C 编号是同型号/同封装的等价件。**标准封装件（0805、SOT-23、SMA/SMB、SOP、TO-252、DO-41）可直接用**；品牌差异不影响焊接 |
| — | 无对应 C 编号，需自建封装或另行匹配 |

> ⚠ **例外：机械件不适用这条。** 开关、连接器、保险丝座、蜂鸣器同名不同厂，脚距可能不同，
> 必须按实物尺寸图核对，见 [待补清单](../pending.md)。

手焊：🟢 `friendly` = 0805/1206/直插等；🟡 `caution` = 方向/引脚密/大散热焊盘。

> **可用电阻阻值只有 11 个。** 设计时不要出现表外阻值；确实需要时先补购再画。
> **AOD4185 只有 5 颗**，没有余量。库存肖特基只有 SS14（SMA），没有 SS34。
> 直插电解**高度均为 11 mm**。板上方要插模块时垂直净空必须留够。
