# 寄存器与数据换算速查

本页只列常用项目。FIFO、中断、APEX、辅助接口和间接寄存器访问以[官方数据手册](../references/chip/ICM-45686-datasheet-rev1.0.pdf)为准。

## 常用寄存器

| 寄存器 | 地址 | 作用 |
|---|---:|---|
| `ACCEL_DATA_X1_UI`…`ACCEL_DATA_Z0_UI` | `0x00`–`0x05` | 三轴加速度原始数据，高字节在前 |
| `GYRO_DATA_X1_UI`…`GYRO_DATA_Z0_UI` | `0x06`–`0x0B` | 三轴角速度原始数据，高字节在前 |
| `TEMP_DATA1_UI`、`TEMP_DATA0_UI` | `0x0C`–`0x0D` | 16 位补码温度数据 |
| `PWR_MGMT0` | `0x10` | 加速度计、陀螺仪工作模式 |
| `FIFO_COUNT_0/1` | `0x12`–`0x13` | FIFO 计数 |
| `FIFO_DATA` | `0x14` | FIFO 数据端口 |
| `INT1_STATUS0` | `0x19` | DRDY、FIFO、复位完成等状态 |
| `ACCEL_CONFIG0` | `0x1B` | 加速度量程与 ODR |
| `GYRO_CONFIG0` | `0x1C` | 陀螺仪量程与 ODR |
| `WHO_AM_I` | `0x72` | 应读取到 `0xE9` |

## 原始数据换算

设原始 16 位补码数据为 `raw`：

- 加速度：`accel_g = raw × 量程_g / 32768`
- 角速度：`gyro_dps = raw × 量程_dps / 32768`
- 温度：`temperature_C = 25 + raw / 128`

FIFO 内温度数据可能使用不同分辨率，不能直接套用 UI 温度公式。

## 随附示例的默认配置

- 加速度计：±4 g、200 Hz。
- 陀螺仪：±1000 dps、200 Hz。
- 两者使用低噪声 LN 模式。
- 数字低通带宽设为 ODR/4。
- INT1 配置为高有效、脉冲、推挽并启用 DRDY。

## 最小联调顺序

1. 上电后等待至少 1 ms；工程中保守使用 3 ms 或更长时间。
2. 读取 `WHO_AM_I` 并确认返回 `0xE9`。
3. 软复位，然后重新配置量程、ODR、滤波和电源模式。
4. 静止读取数据，检查 Z 轴重力方向、零偏、字节序和换算系数。
5. 高采样率场景使用 DRDY 或 FIFO，避免非定时轮询引入采样抖动。
