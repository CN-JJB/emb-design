# 模块识别、规格、接线与首次验证

## 1. 已知对象

现有原始文件只有一张 [淘宝尺寸图](../mechanical/module-15x10mm.webp)，图中可确认：

- PCB 外形约 15.00 mm × 10.00 mm。
- 单排四个通孔，从上到下标为 `VIN`、`GND`、`SDA`、`SCL`。
- 板上标出了传感器位置 `U2`、电源/接口相关器件位置和三轴方向示意。
- 当前图片是尺寸/布局示意，不是原理图，也不是可证明全部器件实装状态的高清正反面照片。

芯片本体是 MEMSIC（美新）MMC5983MA，3.0 mm × 3.0 mm × 1.0 mm LGA16 三轴 AMR 磁传感器。15 mm × 10 mm 是模块 PCB 尺寸，不是传感器芯片尺寸。

## 2. 官方芯片规格

以下数据来自本地 [MMC5983MA Datasheet Rev A](../references/chip/MMC5983MA-Datasheet-RevA.pdf)：

| 参数 | 规格 | 备注 |
|---|---|---|
| 测量范围 | 每轴 ±8 G | 1 G = 100 µT，因此对应 ±800 µT |
| 输出分辨率 | 18 位 | 也可按 16 位高位数据使用 |
| 18 位灵敏度 | 16384 counts/G | 约 0.0625 mG/LSB |
| 16 位灵敏度 | 4096 counts/G | 约 0.25 mG/LSB |
| RMS 噪声 | BW=00 时典型 0.4 mG | 更高带宽噪声更大 |
| 最大数据率 | 1000 Hz | 需要 BW=11 和连续频率 111 |
| I²C | 从设备，最高 400 kHz | 固定 7 位地址 0x30 |
| SPI | 最高 10 MHz | 芯片支持，但当前四针模块没有引出 |
| VDD | 2.8–3.6 V | 典型 3.0 V |
| VDDIO | 2.8–3.6 V | 当前模块具体连接未知 |
| 掉电电流 | 典型 1 µA | 取决于工作配置 |
| 工作温度 | -40 至 +105 ℃ | 模块其他元件未必覆盖同一范围 |
| Product ID | 寄存器 0x2F = 0x30 | 首次通信的首选身份检查 |
| 强场恢复 | 内建 SET/RESET | 超过约 10 G 干扰后应执行 SET/RESET |

数据手册给出的航向精度是满足算法、安装和校准条件后的器件能力，不等于把模块接上后即可直接获得同等整机精度。

## 3. 四针接线

### 推荐的 3.3 V 主控接法

| 模块 | 主控 | 说明 |
|---|---|---|
| VIN | 3.3 V | 当前缺少模块原理图，3.3 V 是符合芯片额定范围的保守选择 |
| GND | GND | 必须共地 |
| SDA | I²C SDA | 逻辑高电平不得超过芯片/模块实际 VDDIO |
| SCL | I²C SCL | 初次建议 100 kHz，稳定后可升至 400 kHz |

### 为什么不直接写“支持 5 V”

原始图片虽然使用 `VIN`，并能看到疑似电源与上拉器件的位置，但没有：

- 模块原理图；
- 电源芯片型号；
- 电阻实际阻值；
- 正反面清晰实物照片；
- 商家对输入电压和逻辑电平的明确规格。

因此不能确认 VIN 是否经过稳压，也不能确认 SDA/SCL 上拉到 VIN、3.3 V 还是其他电源。即使 VIN 能接 5 V，I²C 逻辑也未必具备 5 V 容限。拿到实物后若要使用 5 V，必须先识别 U1、测量传感器 VDD/VDDIO 和总线上拉电压。

## 4. I²C 上拉

MMC5983MA 的 SDA/SCL 是开漏 I²C 总线，需要上拉。官方建议：

- 总线短于 10 cm：可用约 2.7 kΩ。
- 总线短于 5 cm：可用约 10 kΩ。

模块图片上的 R1/R2 可能与上拉有关，但丝印/示意中的 `0603` 只表示封装，不能当作阻值。接主控后先断电测量 SDA、SCL 到电源的电阻，确认模块是否已有上拉，避免多块模块并联后等效阻值过低。

## 5. 首次上电检查

1. 断电检查 VIN 与 GND 是否短路。
2. 使用限流电源或主控 3.3 V，先把限流设在较保守范围。
3. 上电后测量模块供电轨，确认传感器侧不超过 3.6 V。
4. 用 100 kHz I²C 扫描，预期出现 7 位地址 `0x30`。
5. 读取 `0x2F`，预期 Product ID 为 `0x30`。
6. 若地址存在但 ID 不符，不要继续按 MMC5983MA 写控制寄存器；先核对芯片丝印和模块方向。
7. 执行软件复位，等待至少 10 ms。
8. 先做一次低速单次测量，再进入连续模式。

不同平台的 I²C 地址参数容易混淆：

- Arduino、Linux `i2c-dev` 通常填写 7 位地址 `0x30`。
- STM32 HAL 的 `DevAddress` 通常填写左移后的 `0x30 << 1`，即 `0x60`。
- 数据手册示例中的写地址字节是 `0x60`，读地址字节是 `0x61`，它们不是新的 7 位地址。

## 6. 当前模块可用与不可直接用的功能

| 功能 | 当前四针模块 |
|---|---|
| I²C 单次/连续测量 | 可用 |
| 轮询 Status 数据就绪 | 可用 |
| SET/RESET、自动 SET/RESET | 可用，通过寄存器控制 |
| 温度传感器 | 可用，通过寄存器读取 |
| SPI | 不可直接用，相关引脚未引出 |
| INT 数据就绪中断 | 不可直接用，INT 未引出 |

SparkFun 库中的连续测量中断示例依赖 INT 引脚。对本模块应改为轮询 `Status(0x08)` bit 0，或按已知输出频率定时读取并做状态确认。

## 7. 轴向确认

淘宝图给出了彩色轴向示意，数据手册也给出了芯片封装坐标，但模块最终轴向取决于 U2 的实际焊接方向。首次使用建议：

1. 读取静止三轴数据。
2. 用已知方向的小磁体在较远距离缓慢靠近，分别验证 X/Y/Z 正方向。
3. 记录“模块板边方向 → 软件坐标”的映射。
4. 在机体坐标系中统一做轴交换和符号翻转，不要直接复制其他开发板的航向公式。

更详细的数据读取见[寄存器与采样流程](registers-and-measurement.md)，安装和校准见[校准与布局](calibration-and-placement.md)。
