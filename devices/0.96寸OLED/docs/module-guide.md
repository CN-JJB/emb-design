# SSD1306 128×64 四针 I²C OLED 模块使用说明

## 1. 本文适用范围

本文只针对当前实物：0.96 寸、SSD1306、128×64、四针 I²C 模块，排针顺序为 `GND / VCC / SCL / SDA`。外观相似但使用 SH1106、128×32、六针或七针 SPI 接口的模块不能直接套用本文。

商家图片出现蓝色、白色和黄蓝双色版本。这些是 OLED 面板发光材料或区域滤色差异，不改变 128×64 显存组织。黄蓝版本的颜色区域固定，软件不能把任意像素改成另一种颜色。

| 控制器 | SSD1306 | 商家图、I²C 原理图、面板规格书 |
| 像素 | 128×64，1 bit/像素 | SSD1306 与面板规格书 |
| 接口 | I²C，四针 | 当前模块图片与 B 版原理图 |

| OLED 玻璃 | 约 26.7 × 19.268 mm | 四针 B 版结构图 |
| 有效显示区 | 21.744 × 10.864 mm | 结构图与面板规格书 |
| 安装孔 | 内径约 2.0 mm、外径约 3.5 mm | 四针 B 版结构图 |
| 排针间距 | 2.54 mm × 3 个间距 | 四针 B 版结构图 |
| PCB 厚度 | 约 1.5 mm | 四针 B 版结构图 |

尺寸图是商家资料中的 B 版本。该图把排针文字印成 `VCC GND SCL SDA`，与正面丝印、原理图 J1（`GND / VCC_IN / SCL / SDA`）和中景园手册四针照片都不一致。机械尺寸用这张图，接线只看丝印。安装孔内径 2 mm、外径 3.5 mm，不能按商品文案当成 M3。采购其他批次时应再次实测孔位、排针方向和玻璃位置，不要仅凭“0.96 寸 OLED”名称开板。

## 3. 接线

| 模块引脚 | 作用 | MCU 连接 |
|---|---|---|
| GND | 电源地 | GND |
| VCC | 模块输入电源 | 首次调试接 3.3 V |
| SCL | I²C 时钟 | MCU I²C SCL |
| SDA | I²C 数据 | MCU I²C SDA |

商家手册把模块 VCC 标为 3～5.5 V，商品图标为 3.3～5 V。B 版原理图显示输入端经过标为 662K 的约 3.3 V 稳压器，SCL/SDA 各有 4.7 kΩ 上拉到板内 VCC。不同厂家的同外观板不一定完全相同，因此：

1. 3.3 V MCU 首次调试时让模块 VCC 也使用 3.3 V。
2. 如果必须给模块输入 5 V，先确认实物确有稳压器，并测量空闲时 SCL/SDA 高电平不超过 MCU 引脚容许值。
3. I²C 总线只需要一组合适的上拉；板载与主板上拉并联过小会增加低电平灌电流。

## 4. I²C 地址：`0x3C` 与 `0x78` 是同一个地址

SSD1306 的 7 位从机地址由 SA0 决定：

| SA0 | 7 位地址（驱动 API 常用） | 8 位写地址字节（旧资料常写） |
|---|---|---|
| 0 | `0x3C` | `0x78` |
| 1 | `0x3D` | `0x7A` |

换算关系是 `8 位写地址 = 7 位地址 << 1`。当前商家原理图注明默认写地址为 `0x78`，因此程序通常应填写 `0x3C`。如果 I²C 扫描器找到 `0x3D`，说明地址焊盘/SA0 配置与默认值不同。

常见错误是把 `0x78` 传给只接受 7 位地址的 Arduino `Wire`、ESP-IDF 或 STM32 驱动，结果总线无应答。另一个易踩点是 Adafruit SSD1306 库在地址参数为 0 时会按尺寸选择默认地址，对 128×64 默认到 `0x3D`；本模块应显式指定 `0x3C`。

## 5. 显存、页与传输格式

- 完整帧缓冲：`128 × 64 ÷ 8 = 1024` 字节。
- SSD1306 GDDRAM 可看成 8 页，每页 128 字节；每个字节的 8 位对应同一列的 8 个垂直像素。
- I²C 地址之后还需控制字节。常用值为 `0x00`（后续为命令）和 `0x40`（后续为显示数据）。
- 使用水平寻址模式时，常以 `0x21` 设置列范围 0～127，以 `0x22` 设置页范围 0～7，然后连续发送 1024 字节。
- `0xA0/0xA1` 控制 Segment 重映射，`0xC0/0xC8` 控制 COM 扫描方向；屏幕镜像或上下颠倒时先核对这两组命令。

## 6. 首次点亮流程

### 6.1 硬件检查

1. 对照模块丝印确认排针顺序，不能按另一家模块的照片猜测。
2. 先用 3.3 V 供电并共地。
3. 运行 I²C 扫描，先找 `0x3C`，再检查 `0x3D`。
4. 总线无设备时，用示波器或逻辑分析仪确认 SCL/SDA 有上拉、起始条件和 ACK。

四针版本没有引出 RES。商家 B 版原理图包含 RC 上电复位，因此正常情况下无需 MCU 额外控制复位脚；上电时仍应留出短暂稳定时间后再初始化。

### 6.2 推荐驱动方式

Arduino/ESP32 Arduino 环境可使用本地固定版本的 Adafruit SSD1306，并通过 Library Manager 同时安装 `Adafruit GFX Library`。构造器使用 128×64、I²C 和 `reset=-1`，初始化时显式传入 `0x3C`：

```cpp
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

Adafruit_SSD1306 display(128, 64, &Wire, -1);

void setup() {
  Wire.begin();  // ESP32 如需自定义引脚，可用 Wire.begin(SDA_PIN, SCL_PIN)
  if (!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {
    for (;;) {}
  }
  display.clearDisplay();
  display.setTextColor(SSD1306_WHITE);
  display.setCursor(0, 0);
  display.print("SSD1306 OK");
  display.display();
}

void loop() {}
```

STM32 HAL、裸机或其他平台也可按相同地址和命令工作，但 I²C 句柄、超时和 DMA 分包策略由平台驱动决定。

### 6.3 典型 128×64 初始化序列

优先使用成熟库。需要自写驱动时，可用下面的内部电荷泵配置作为起点，并逐项对照 Rev 1.1 数据手册：

```text
AE          display off
D5 80       display clock
A8 3F       multiplex ratio = 63
D3 00       display offset = 0
40          start line = 0
8D 14       enable internal charge pump
20 00       horizontal addressing mode
A1          segment remap
C8          COM scan direction remap
DA 12       COM pins for 128×64
81 CF       contrast (adjust as needed)
D9 F1       pre-charge for switch-cap VCC
DB 40       VCOMH deselect level
A4          resume RAM display
A6          normal display
2E          deactivate scroll
AF          display on
```

不要把某个库的对比度值当成硬性规格。为减小功耗和老化，应把 `0x81` 对比度调到满足可读性的最低值。

## 7. 常见故障定位

| 现象 | 优先检查 |
|---|---|
| 扫描不到设备 | 地址制式是否填错、SCL/SDA 是否反接、是否共地、上拉和供电 |
| 扫到设备但全黑 | 是否发送 `AF`、电荷泵是否为 `8D 14`、初始化后是否真正刷新显存 |
| 全亮或花屏 | 控制字节 `0x00/0x40`、缓冲区长度、列/页范围、供电稳定性 |
| 左右或上下镜像 | `A0/A1` 与 `C0/C8` |
| 画面偏移约 2 列 | 很可能程序按 SH1106 的 132 列显存偏移编写；本模块按 SSD1306 的 128 列处理 |
| 只显示 32 行 | 驱动尺寸选成 128×32，或 multiplex/COM 配置错误 |
| 偶发 NACK | I²C 频率、线长、上拉值、电源纹波、一次传输是否超过平台缓冲限制 |

## 8. SSD1306 与 SH1106 不可混用

两者都常被装在 0.96/1.3 寸 OLED 板上，外观和基础命令相似，但显存列数、寻址方式和部分命令不同。SSD1306 是 128 列 GDDRAM；SH1106 常见为 132 列并需要列偏移。当前目录的识别依据同时来自商家图、B 版原理图、面板规格书和 SSD1306 手册，因此这里不收录 SH1106 驱动。

## 9. 使用寿命与显示策略

OLED 会随累计发光时间和亮度老化，长期静止高亮图形还可能产生残影。建议降低对比度、避免长期全白、周期性熄屏或移动固定 UI，并在不需要显示时发送 `AE`。黄蓝版本的分色边界是物理固定区域，不属于烧屏故障。
